ccus 经 Codex CLI 采集额度（app-server RPC 主路径 + wham/usage 回退）与 sessions 数据（消息 / 请求 / token），落盘 source="codex" 事件并接入 export / aggregate。

1. 触发与编排

每个 Codex turn 结束经 Stop hook 调起 ccus 隐藏命令（__codex-notify 为保留入口、当前默认不走——orca 等会覆盖 config.toml 致 notify 不持久，install --codex 只装 hook），共享 recordCodexEvent 完成拉额度 → 落盘 → 兜底同步，全程不写 stdout、失败静默 exit 0。

2. 额度采集决策（resolveCodexQuota）

5min TTL 缓存优先；过期走 spawn codex app-server 主路径；仅主路径 unavailable（本机无 codex CLI）才回退 wham/usage HTTP 直连，error（超时 / RPC 错）不回退；wham 经统一 env 代理（CCUS_PROXY 优先）。
